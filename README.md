# 🌱 موقع تعليمي: الميزانية الشبكية والخرائط الكنتورية

## 📋 وصف المشروع
موقع تعليمي تفاعلي متكامل لشرح وحدة **"الميزانية الشبكية والخرائط الكنتورية"** لطلاب برنامج فني هندسة زراعية - الصف الثالث. يقدم الموقع شرحاً مبسطاً مع رسومات توضيحية وأسئلة تفاعلية ومسائل تطبيقية مع حلولها.

## ✨ المميزات الرئيسية

### 1. **تصميم متجاوب بالكامل**
- يعمل على جميع الأجهزة (كمبيوتر، تابلت، جوال)
- يتكيف مع جميع أحجام الشاشات
- واجهة مستخدم سهلة وبسيطة

### 2. **قائمة تنقل ذكية**
- قائمة علوية ثابتة مع تأثيرات عند التمرير
- في الشاشات الصغيرة تتحول إلى زر قائمة (Menu) واحد
- إمكانية إخفاء القائمة عند التمرير لأسفل وإظهارها عند التمرير لأعلى

### 3. **المحتوى التعليمي**
- 7 أقسام رئيسية تغطي جميع جوانب الوحدة
- شرح نظري مبسط مع أمثلة عملية
- رسومات توضيحية لخرائط الكنتور
- جداول وبيانات تفاعلية

### 4. **الأسئلة والتدريبات**
- 8 أسئلة اختيار من متعدد
- تصحيح فوري مع تغذية راجعة
- حساب الدرجة النهائية مع نسبة مئوية

### 5. **المسائل التطبيقية**
- 4 مسائل هندسية كاملة
- خطوات حل مفصلة
- إمكانية إدخال الإجابة والتحقق منها
- تقدير نسبة الدقة مع تحليل الإجابة

### 6. **دعم كامل للغة العربية**
- جميع النصوص والأرقام بالعربية
- استخدام الحروف العربية (أ، ب، ج، د)
- القانون مكتوب بالعربية: `مكعبات الحفر أو الردم (م³) = (س ÷ ٤) × (أ + ٢ب + ٣ﺟ + ٤د)`
